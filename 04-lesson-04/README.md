# Lesson 04: Aggregation & Groups

**Promise:** you can collapse thousands of rows into one summary row, group
rows by any column, and filter the *groups* (not just the rows) with
`HAVING`. By the end you can answer "who spent the most?", "how many per
genre?", and "which customers bought a big invoice?" without exporting the
data to a spreadsheet.

**Prerequisite:** Lessons 01–02 (`SELECT`/`ORDER BY`, `WHERE`).

**Files:** `lesson.md` (everything, including the quiz),
`answers_practical.md`, and `answers_quiz.md`

**Keywords:** `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, `HAVING`,
`DISTINCT`, `ROUND`

**No reset needed** — this lesson only reads.
