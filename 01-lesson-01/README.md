# Lesson 01: Your First Query

**Promise:** by the end of this lesson you can open the Chinook database and
write your own SQL queries that select columns, remove duplicates, name your
output clearly, sort it, and page through it.

**You need from before:** the setup in [00-getting-started/](../00-getting-started/)
— SQL Explorer open with `chinook.db` loaded.

**Keywords this lesson:** `SELECT`, `FROM`, `*`, `DISTINCT`, `AS`, `ORDER BY`,
`ASC`, `DESC`, `LIMIT`, `OFFSET`

**Files in this folder:** [lesson.md](lesson.md) (read and do this),
[answers_practical.md](answers_practical.md), and
[answers_quiz.md](answers_quiz.md) (open only after attempting the work).
